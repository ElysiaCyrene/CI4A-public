# Release workspace

- This repository contains Eous, three CI4A component libraries and their WebArena frontends.
- Keep exactly five bundled WebArena task files: 0, 1, 11, 107, 108. Do not add private task sets, admin/Traccar tasks, logs, or database snapshots.
- Secrets belong in ignored .env files. Do not print their values or commit them.
- Preserve third-party LICENSE files and attribution. Do not replace legal attribution with anonymous placeholders.
- Runtime packages are intentional release inputs. Keep runtime fixes consistent with library sources.
- Use pnpm and read README.md before installing. Do not copy dependencies or Git history from a private checkout.
- Run the release audit before staging for publication. Model termination is not benchmark success.
- Do not publish or push unless the user requests it.
